# Password Manager

Hopefully you now have a Proton account and a new Proton Mail address.  If not, start there first by clicking [HERE](Mail.md).

Your online passwords are the next thing you should try to secure.  The problem at the moment is that you probably re-use passwords.  Imagine your passwords currently look something like this -

| Website       | Password      |
| ------------- | ------------- |
| Amazon        | Pa55w0rd55    |
| Ebay          | S5cr3t55      |
| Facebook      | Pa55w0rd55    |
| Boots.com     | Pa55w0rd55    |

Now imagine Boots.com gets hacked and their customers passwords are all stolen.  Not only is your Boots.com account compromised but the first thing the hackers will do is try that password on other sites.  So now your Amazon and Facebook account is also compromised.

For this reason we want to have a **long, random, unique** password for every single website you use.  And the only way you can manage this many unique passwords is with a password manager like Proton Pass.

We aim to end up with something like this -

| Website       | Password      |
| ------------- | ------------- |
| Amazon        | aBmfgVUhV6x3(C&(^)%E    |
| Ebay          | m?K2&ud3y!H6HUx&]UV%      |
| Facebook      | vCu*s;:kDD7UZ;za]&bh    |
| Boots.com     | +!*z!:fwq8B;qt&bsD3r    |

Now if Boots.com gets hacked your Boots.com is compromised.  But only your Boots.com account and nothing else.

And all you will need to remember is your Proton account password.
